# TechMock AI

**Nền tảng Giả lập Phỏng vấn và Đánh giá Kỹ thuật tích hợp AI chuyên sâu.**

## 1. Giới thiệu

TechMock AI là nền tảng hỗ trợ người dùng luyện tập phỏng vấn kỹ thuật thông qua các tình huống mô phỏng thực tế, kết hợp trí tuệ nhân tạo (AI) để đánh giá năng lực lập trình, tư duy giải quyết vấn đề và kiến thức chuyên môn.

## 2. Mục tiêu dự án

- Mô phỏng môi trường phỏng vấn kỹ thuật thực tế.
- Xây dựng AI Mentor tương tác với người dùng.
- Hỗ trợ lập trình và thực thi mã nguồn trực tiếp.
- Phân tích, đánh giá và đề xuất cải thiện năng lực.
- Quản lý hồ sơ, lịch sử phỏng vấn và báo cáo kết quả.

## 3. Công nghệ dự kiến

| Thành phần       | Công nghệ                   |
| ---------------- | --------------------------- |
| Frontend         | Next.js, React, TypeScript  |
| Backend          | Node.js, NestJS, TypeScript |
| Database         | PostgreSQL                  |
| ORM              | Prisma                      |
| Package Manager  | pnpm                        |
| Source Control   | Git, GitHub                 |
| Containerization | Docker                      |

## 4. Kiến trúc dự án

Dự án định hướng phát triển theo mô hình Monorepo kết hợp Modular Monolith.

- apps/: Các ứng dụng chính.
- packages/: Các thư viện và thành phần dùng chung.
- infra/: Hạ tầng và cấu hình triển khai.
- docs/: Tài liệu phân tích và thiết kế.

## 5. Trạng thái phát triển

Dự án đang trong giai đoạn khởi tạo nền tảng, thiết kế kiến trúc và thiết lập môi trường phát triển.

## 6. Định hướng

Xây dựng một nền tảng luyện phỏng vấn kỹ thuật toàn diện, có khả năng mở rộng và ứng dụng AI vào quá trình đào tạo, đánh giá năng lực lập trình.
